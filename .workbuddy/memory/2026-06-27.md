## 修复推送失败问题
- **症状：** 一键更新脚本推送失败，"Remote has newer commits, pulling & rebasing..." 后重试3次仍失败
- **根因：** 远程仓库有未知来源的新提交（ae9dc55, 2026-06-26），`git pull --rebase` 导致 data.json 冲突卡住，脚本无冲突处理逻辑，后续 push 全部失败
- **处理：**
  1. `git checkout --theirs data.json` 取本地今日数据，`git rebase --continue` 完成 rebase
  2. 推送成功：8840fdc update data 2026-06-27
- **预防修复：** 更新 `update_data.ps1` 的 `Push-WithRetry` 函数，新增 rebase 冲突自动检测与解析逻辑：
  - 检测 `.git/rebase-merge` / `.git/rebase-apply` 目录判断是否卡在冲突
  - 对 data.json 自动 `--theirs`（取本地生成版本）
  - 非交互式 `GIT_EDITOR=true git rebase --continue`
  - 失败则 `git rebase --abort` 回滚，避免残留状态
